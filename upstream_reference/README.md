# Upstream reference files

This folder retains the original notebooks, Python source files, and README from the public UCM CatTracks Simulator project for provenance and comparison.

These files are retained as upstream reference material and are **not** used by the new DA-012 execution workflow. The original notebooks rely on hard-coded column slices and workbook paths. The runnable student adaptation is `../notebooks/DA012_Ridership_Analysis.ipynb` and `../src/ridership_analysis.py`.
