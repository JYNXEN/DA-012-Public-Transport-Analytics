# Source datasets

The two Excel workbooks in this folder are supplied with the upstream UCM CatTracks Simulator repository:

https://github.com/nlt-python/UCM_CatTracks_Simulator

They are included here unchanged for reproducibility. The analysis reads the aggregate `PAX ON` tables from the `C1 BLUE`, `C1-GOLD`, `C2 - EXPRESS`, and `G-Line` worksheets in each workbook.

The workbooks contain more than these four route sheets. This student analysis intentionally limits scope to the four weekday routes used by the upstream exploratory analysis.

See `../NOTICE.md` for attribution and the upstream licence statement.
